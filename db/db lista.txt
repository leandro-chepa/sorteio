Como funciona o sorteio

SELECT *
FROM filmes
WHERE ativo = 1
ORDER BY RANDOM()
LIMIT 1;

Depois do sorteio:

UPDATE filmes
SET
ativo = 0,
vezes_sorteado = vezes_sorteado + 1
WHERE id = ?;
